# Responsive Landing Page – NovaTech

## Project Overview
This project is a responsive landing page designed for a fictional startup called **NovaTech**.  
The website showcases a modern homepage layout with sections for navigation, features, testimonials, and footer information.

The page is fully responsive and works on both desktop and mobile devices.

---

## Features
- Responsive Design
- Modern UI Layout
- Flexbox-based Structure
- Smooth Scrolling
- Hover Effects
- Mobile Friendly Navigation
- Testimonials Section
- Gradient Header Design

---

## Technologies Used
- HTML5
- CSS3
- Flexbox
- Google Fonts (Poppins)

---

## Sections Included
1. Header & Navigation
2. Hero Section
3. Feature Highlights
4. Testimonials
5. Footer
